# gitorko blog

## Setup

```bash
git submodule add https://github.com/chipzoller/hugo-clarity themes/hugo-clarity
git submodule add https://github.com/martignoni/hugo-notice.git themes/hugo-notice
```

Start server
```bash
hugo server
```

```bash
hugo server -D
```
