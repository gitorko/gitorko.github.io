# gitorko blog

## Setup

Checkout code

```bash
git clone https://github.com/gitorko/gitorko.github.io.git gitorko
cd gitorko
git checkout -b blog origin/blog
git submodule update --init --recursive
```

Start server

```bash
hugo
hugo server
```
