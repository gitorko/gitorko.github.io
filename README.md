# gitorko blog

## Setup

Checkout code

```bash
git clone https://github.com/gitorko/gitorko.github.io.git gitorko
cd gitorko
git checkout -b blog origin/blog
git submodule update --init --recursive
```

Start server

```bash
https://github.com/gohugoio/hugo/releases/download/v0.125.4/hugo_extended_0.125.4_darwin-universal.tar.gz


hugo version
hugo v0.125.4-cc3574ef4f41fccbe88d9443ed066eb10867ada2 darwin/amd64 BuildDate=2024-04-25T13:27:26Z VendorInfo=gohugoio

hugo server
hugo --ignoreCache
hugo server --ignoreCache
```
